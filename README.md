# 🅿️ חנייה - פתח שער

אפליקציית Android לפתיחת שערי חנייה בחיוג אוטומטי, עם ממשק גדול ונוח
לשימוש גם תוך כדי נהיגה (דרך מולטימדיה של הרכב המחובר בבלוטוס לטלפון).

## איך זה עובד

לחיצה על כפתור שער מבצעת חיוג רגיל (`ACTION_CALL`) למספר המשויך אליו.
אם הטלפון מצומד בבלוטוס למערכת המולטימדיה של הרכב, מערכת ההפעלה
מנתבת את השיחה לרכב אוטומטית - האפליקציה לא צריכה קוד מיוחד לכך,
זו התנהגות סטנדרטית של אנדרואיד.

## תכונות

- שני שערים מוגדרים מראש (חנייה עילית / תת קרקעית), ואפשר להוסיף עוד
- לחיצה ארוכה על כפתור שער -> עריכה מהירה (שם + מספר) או מחיקה
- כפתור הגדרות (⚙️) לניהול כל השערים
- צליל אישור לאחר חיוג מוצלח
- תמיכה מלאה בעברית ו-RTL
- עיצוב שמתאים את עצמו לגודל המסך (Light/Dark mode כלול)

## בנייה (ללא Android Studio!)

הפרויקט נבנה אוטומטית ב-GitHub Actions בכל פעם שדוחפים קוד ל-`main`.
לאחר שהבנייה מסתיימת בהצלחה, ה-APK זמין תחת:

```
Actions -> הבנייה האחרונה -> Artifacts -> app-debug-apk
```

### בנייה מקומית (אופציונלי, אם יש Gradle מותקן)

```bash
gradle assembleDebug
```

ה-APK ייווצר בנתיב:
```
app/build/outputs/apk/debug/app-debug.apk
```

## שינוי מספרי הטלפון

הכי קל - ישירות באפליקציה: לחיצה ארוכה על כפתור השער -> עריכה.

אפשר גם לערוך את ברירת המחדל בקוד, בקובץ:
`app/src/main/java/com/parking/gate/control/MainActivity.kt`
בפונקציה `loadGates()`.

## הרשאות

| הרשאה | שימוש |
|---|---|

| `BLUETOOTH*` | תמיכה בניתוב שיחה למולטימדיה ברכב |
